## Overview

**Trainify** is a desktop-based training period management system featuring a built-in web interface, PDF and JSON export support, and system tray integration.

## Key Features

- **Desktop Training Period Management:** Organize, track, and manage training periods directly from your desktop.
- **Built-in Web Interface:** Access and monitor training data through an integrated web UI.
- **PDF & JSON Export:** Export records and schedules cleanly into PDF or JSON formats.
- **System Tray Integration:** Keep Trainify running quietly in the background with quick access from the system tray.
